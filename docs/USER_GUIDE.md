# User guide

Install MineOpsWeb from the browser’s Add to Home Screen flow. Today shows current freshness and actionable manager opportunities. Managers is catalog-backed and searchable; open a card for abilities and ownership. Strategy is a library of short plans: start with **Frontier Mine start**, then use General lineup or Upgrade focus only when needed. For Frontier Mine, sync first, then use the roster roles and FC checkpoint planner as a planning aid; compare the displayed current in-game barrier cost before spending Credits.

More contains sync, diagnostics, imports, rollback, export/import and installation help. To update game catalog data manually, open **More → UbuntuMac catalog bridge**, copy the command or run the VS Code task `UbuntuMac: Check APK + upload latest release` on your Mac, then refresh bridge status and the active catalog package. The browser cannot itself start an APK capture on UbuntuMac. Offline cached data remains readable; sync again when connectivity returns.
