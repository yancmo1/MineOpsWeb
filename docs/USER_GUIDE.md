# User guide

Install MineOpsWeb from the browser’s Add to Home Screen flow. Today shows current freshness and actionable manager opportunities. Managers is catalog-backed and searchable. An owned manager card shows its currently unlocked passive codes; open the card to see passive names, values, and unlock milestones. A manager with level 30 / promotion 3 will show its Mine Income Factor as **Unlocked** when that passive is part of its APK master-data definition. Future passives remain visible as locked and are not counted by Strategy.

Strategy is a library of short plans: start with **Frontier Mine start**, then use General lineup or Upgrade focus only when needed. For Frontier Mine, sync first, then enter the live barrier cost, remaining wait in minutes, barrier skips, and Time Jumps. The planner uses those values to recommend **Wait**, **Spend FC**, or **Run a burst**; open “Assumptions used” before acting, and keep the in-game screen as the source of truth.

More opens with quick actions and four health cards for player data, strategy catalog, cloud account, and the capture bridge. Use **Player sync** for Kolibri credentials and manual sync, **Catalog & strategy data** to refresh the verified package and confirm **Exact levels active**, **History & recovery** for snapshots and imports, and **Diagnostics & about** when troubleshooting. Sections are collapsible and keyboard accessible; important sync and refresh actions remain visible near the top on phones.

To update game catalog data manually, open **More → Capture bridge**, copy the command or run the VS Code task `UbuntuMac: Check APK + upload latest release` on your Mac, then refresh bridge status and the active catalog package. The browser cannot itself start an APK capture on UbuntuMac. Offline cached data remains readable; sync again when connectivity returns. Export/import and full reset controls are not yet implemented.
